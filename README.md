PETUALANGAN ANGKA — KELAS 1–6 SD
Versi angka-pid-1 • 3 November 2026

ISI GAME
180 soal matematika dasar, 30 soal per kelas, dengan empat pilihan jawaban
dan pembahasan. Setiap sesi mengambil 25 soal secara acak dari kelas yang
dipilih. Urutan soal serta pilihan jawaban diacak.

Kelas 1: Bilangan sampai 20, tambah-kurang, urutan dan bentuk dasar.
Kelas 2: Hitung sampai 100, perkalian awal, nilai tempat, uang dan waktu.
Kelas 3: Perkalian, pembagian, pecahan sederhana, ukuran dan keliling.
Kelas 4: Operasi, pecahan senilai, luas, keliling, faktor dan sudut.
Kelas 5: Desimal, penjumlahan pecahan, persen, volume dan rata-rata.
Kelas 6: Bilangan bulat, operasi pecahan, rasio, diskon dan bangun ruang.

Materi merupakan latihan dasar bertahap, bukan pengganti seluruh materi
matematika dalam satu tahun pelajaran. Guru dapat memilih kelas sesuai
kesiapan murid. Pecahan ditulis a/b; tanda koma dipakai untuk desimal.

CARA MEMASANG DI PID HISENSE
1. Ekstrak ZIP. Unggah seluruh isi folder petualangan-angka-pid-hisense
   ke hosting HTTPS. index.html dan folder aset harus berdampingan.
2. Gunakan alamat baru, misalnya /petualangan-angka/, agar tidak tertukar
   dengan game lama dan cache browser.
3. Buka alamat tersebut di PID, pilih kelas dan mode, lalu Mulai Petualangan.
4. Izinkan kamera. Pilih kamera bawaan/USB yang sesuai pada layar latihan.
   Pada Android, mode awal adalah Kompatibel (CPU).
5. Pilih Tahan telapak, arahkan telapak ke target, dan tahan sampai bar penuh.
   Setelah latihan berhasil, tekan Mulai Bermain • Layar Penuh.

KONTROL
- Mode awal mengikuti Penjaga Rimba: tahan telapak sekitar 0,36 detik
  pengamatan kamera. Respons nyata bergantung kecepatan sensor.
- Mode lama 3 pukulan tersedia pada pilihan Kontrol di layar latihan.
- Sentuh/klik satu kali juga dapat menjawab tanpa kamera.
- Keyboard P1: Q/W/A/S atau 1/2/3/4. P2: I/O/K/L.
- Tersedia Solo vs COM, Duel 2 Pemain, 2P Kooperatif, dan Lomba 4 Pemain.
- Setelah selesai, lihat skor, kunci jawaban, dan cara menghitung.

PERBAIKAN PID DIPERTAHANKAN
CSS siap pakai, target diam dalam mode tahan, efek kamera ringan, pemrosesan
Worker, input sensor maksimal 640 × 480, serta model kamera lokal tetap ada.
Jika arah tangan terbalik, gunakan Cermin. Jika lambat, tunggu pemanasan
sekitar 15 detik dan bandingkan Kompatibel (CPU) dengan Otomatis.

Jangan membuka index.html dari dalam ZIP atau melalui file:// untuk kamera.
Gunakan hosting HTTPS atau localhost. Jangan mengunggah HTML tanpa aset.

PENGUJIAN
45 tes otomatis lulus. Seluruh 180 soal dan pilihan jawabannya diperiksa
melalui browser. Pilihan kelas, empat mode bermain, sentuh, keyboard, tahan
telapak, jeda, dan pembahasan berhasil diuji. Model kamera lokal berhasil
memproses gambar simulasi dengan CPU/Worker.
Performa dan akurasi pada PID Hisense fisik belum diuji langsung.
